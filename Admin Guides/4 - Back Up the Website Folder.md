# Guide 4: Back Up the Website Folder

**What this does:** keeps an extra copy of the website files in iCloud.

GitHub already saves every version you publish (Guide 3), so this is an extra safety net.

## Rules

- **Work in the folder on your Desktop:** Desktop > SEPALibrary. That is the working copy.
- **Do not move or sync the working folder** into iCloud Drive, Google Drive or Dropbox.
  Cloud syncing clashes with GitHub's hidden files and causes errors when publishing.
- **Copy, don't move,** when backing up.

## Steps

1. Open **Finder** and click **Desktop**.
2. Hold the **Option** key and drag the **SEPALibrary** folder into **iCloud Drive**.
   (Holding Option makes a copy instead of moving it.)
3. Rename the copy with the date, for example **SEPALibrary backup 2026-10-02**.

Make a backup after big changes. Older backups can be deleted whenever you like.

## Check this setting once

**System Settings > [your name] > iCloud > iCloud Drive > "Desktop & Documents Folders"**.
If it's on, your Desktop is already syncing to iCloud. That's usually fine, but if
GitHub Desktop ever shows strange errors, this setting is the first thing to check.
