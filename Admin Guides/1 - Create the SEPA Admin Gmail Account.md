# Guide 1: Create the SEPA Admin Gmail Account

**What this does:** creates a shared Google account that owns the website's Google Sheet,
so the site doesn't depend on anyone's personal email and can be handed to future admins.

**Do this before Guide 2.**

## Steps

1. Open a private browser window (Chrome: **File > New Incognito Window**) so you don't
   mix it up with your personal Google account.
2. Go to **accounts.google.com/signup**.
3. Fill in a name like **SEPA Library Admin**.
4. Choose an address like **sepalibrary.admin@gmail.com** (pick whatever is available).
5. Choose a strong password and store it somewhere safe (for example, Apple Passwords).
6. **Add a recovery phone number and recovery email.** This keeps the account from being
   locked out. Use a phone number that belongs to a current admin.
7. Finish the signup.

## Afterwards

- Write down the address here for future admins: ______________________
- Do Guide 2 while logged into this account.

## Adding other admins later

Don't share this password. Share the Google Sheet with each admin's own email instead
(Guide 5 explains how). Keep this account's password with one or two trusted people only.
