# Admin Guides: Start Here

Step-by-step guides for running the SEPA Resource Library website (sepalibrary.org).
Do the numbered guides in order the first time.

| Guide | What it does | When |
|---|---|---|
| **1 - Create the SEPA Admin Gmail Account** | Makes a shared Google account that owns the site's data | Once, first |
| **2 - Connect Shift Signup and Forums to Google** | Turns on the shift calendar and forums so entries are saved | Once, after Guide 1 |
| **3 - Publish Website Changes (GitHub Desktop)** | Sends changes from your Mac to the live website | Every time something changes |
| **4 - Back Up the Website Folder** | Makes an extra copy in iCloud | After big changes |
| **5 - Manage Shift Signups and Forum Posts** | Day-to-day admin tasks in the Google Sheet | Ongoing |

## Where things live

- **Working folder:** Desktop > SEPALibrary (work here)
- **Live website:** sepalibrary.org
- **All versions:** GitHub (github.com/jssst21/SEPALibrary)
- **Signups and forum posts:** Google Sheet "SEPA Library Data" in the SEPA admin Google account
- **The one setting that connects the site to Google:** js/config.js
