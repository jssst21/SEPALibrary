Install SEPA Tools on Android

To put the SEPA Tools App on your Android phone:

  1. 1
    Point your phone's camera at this code and tap the link that appears. Open it in Chrome.Tap this button. It opens the SEPA Tools page in Chrome.Open SEPA Tools
  2. 2If Chrome offers Install app, tap it. Done!
  3. 3Otherwise tap the menu at the top right.
  4. 4Tap Add to Home screen (or Install app), then Add.

Then tap the red SEPA Tools icon on your home screen any time.
